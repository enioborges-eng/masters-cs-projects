# Network Principles in Practice — Linux

## Resume in UTM

1. Start the Ubuntu VM in UTM (Network Mode: **Shared Network**).
2. From Mac Terminal, connect with `ssh vagrant@192.168.64.2` and enter the Ubuntu password.
3. In Ubuntu, go to the cloned lab: `cd ~/npp-linux-02-router/demo2-bgp`.
4. Continue with the `demo2-bgp` README and `lab1/part1` assignment. SSH is already enabled; no setup needs repeating.

To finish, type `exit`, then shut down Ubuntu cleanly with `sudo poweroff` before quitting UTM.
